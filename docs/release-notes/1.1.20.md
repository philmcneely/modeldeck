# ModelDeck 1.1.20

Claude cards can now lead with the window you actually plan around, for the whole deck or one account at a time, and Anthropic's unexplained codename windows stay off the deck until they mean something.

**Choose which window leads each Claude card.** Settings → General has a new "Claude cards lead with" picker: Lowest window, 5-hour limit, Weekly · all models, or Model weekly (e.g. Fable). It replaces the old "Lead with the model window" switch. Right-click any Claude card → Lead With to pick a different window for just that card; the header's calendar button still switches every card to the all-models weekly while it is on. Opus 5.5 draws from the all-models weekly, and Anthropic reports no Opus-specific window, so that is the window to watch if Opus is your daily model. If you had the old switch on, the picker starts at Model weekly and nothing moves until you choose. The health chip and the menu-bar health dot follow the choice: they judge the Fable pool only while cards lead with the model window. (#746)

**Codename windows stay hidden until they carry usage.** Anthropic's usage data includes limit kinds with names like "iguana necktie" that nobody outside Anthropic has documented. One started arriving with an expiry date, which slipped past the rule that hid "nimbus quill". A window the deck has no name for now stays hidden until it reports real usage, whatever its reset date says, and appears the moment something draws on it. (#745)

Rollback floor: unchanged
