# ModelDeck 1.1.21

Account status stays responsive while ModelDeck counts shared conversations in the background. Large conversation histories no longer hold up status updates and leave accounts looking stale or disconnected.

Fresh Claude sign-ins are recognized even when an existing credentials file contains only MCP credentials.

The bundled CLIProxyAPI moves to 8.0.40, including authorization checks on each WebSocket turn and corrected credential selection for Codex clients. Updating ModelDeck does not replace a separately managed proxy.

Account cards now offer a weekly usage graph with an even-pace comparison and reset timing.

The phone usage page now includes Deck, Room, and Grid views and remembers your selection.

Rollback floor: unchanged
